# TradingApp

Дашборд статистики торгового счёта MetaTrader 4/5: подключается к твоему счёту,
считает результаты и показывает, что именно съедает прибыль.

Работает локально, на твоём компьютере. Данные счёта никуда не уходят — вся
история лежит в SQLite-файле рядом с приложением.

## Что показывает

**Обзор** — итоговый P&L, винрейт, профит-фактор, средняя сделка, максимальная
просадка, комиссии и свопы, кривая баланса с зоной просадки, результат по месяцам.

**Инструменты** — какие пары приносят деньги, а какие сливают: P&L, винрейт,
профит-фактор и средняя сделка по каждому символу, отдельно покупки против продаж.

**Время** — разбивка по дням недели, часам входа, месяцам и длительности сделки,
плюс календарь по дням. Сразу видно, в какие часы торговать не стоит.

**Риск и дисциплина** — то, чего обычно не видно в отчёте терминала:

- сколько сделок шло без стоп-лосса и сколько это стоило;
- распределение по R (результат, делённый на риск по стопу) и матожидание в R;
- ровность риска на сделку — коэффициент вариации и самые крупные отклонения;
- убытки, вышедшие за плановый риск (проскальзывание, гэп, отодвинутый стоп);
- держишь ли убытки дольше прибыли;
- дни с перебором сделок и их результат против обычных дней;
- похожие на отыгрыш входы — увеличенный объём в течение 30 минут после убытка.

**Сделки** — полный список с сортировкой, риском и R по каждой сделке, выгрузка в CSV.

## Как это открыть

Это **не сайт в интернете**, а программа, которая работает на твоём компьютере и
открывается в браузере по локальному адресу `http://127.0.0.1:8420`. Так и задумано:
приложение должно видеть твой терминал MetaTrader и твою историю сделок, поэтому
живёт на твоей машине, а не на чужом сервере. Ссылки, которую можно кому-то
отправить, здесь нет.

### Windows

1. Установи Python с https://www.python.org/downloads/ — при установке обязательно
   поставь галочку **«Add python.exe to PATH»** на первом экране.
2. Скачай проект: на странице репозитория **Code → Download ZIP**, затем распакуй
   папку, например в `C:\TradingApp`.
3. Зайди в распакованную папку и запусти **`run.bat`** двойным кликом.
4. Первый запуск ставит зависимости — это пара минут. Дальше браузер откроется сам
   на `http://127.0.0.1:8420`.

Чёрное окно консоли не закрывай: в нём и работает приложение. Закроешь окно —
дашборд перестанет открываться, это нормально. Чтобы запустить снова, снова
кликни `run.bat`.

Если Windows ругается «Этот файл скачан из интернета» — нажми
*Подробнее → Выполнить в любом случае*.

### macOS / Linux

```sh
git clone https://github.com/qquebak-ai/TradingApp.git
cd TradingApp
git checkout claude/trading-app-statistics-5r7nsg
./run.sh
```

Открой `http://127.0.0.1:8420`.

### На своём сервере (доступ с телефона)

Дашборд можно поставить на VPS и открывать с телефона из любой точки. Учти три вещи.

**Живая синхронизация с MT5 на Linux-сервере не работает** — пакет `MetaTrader5`
существует только под Windows. На сервере остаётся импорт отчёта, а лучший вариант —
держать MT5 у себя на Windows и запускать агента, который сам шлёт историю на сервер:

```sh
python tools/mt5_agent.py --url https://trading.example.com --token ТОКЕН --interval 300
```

**Обязательны HTTPS и токен.** Без них история счёта и сам токен идут по сети
открытым текстом, а страницу находят сканеры портов за пару дней.

**Нужен отдельный поддомен**, например `trading.example.com`, а не подпапка вида
`example.com/trading`: фронтенд запрашивает `/static` и `/api` от корня сайта.

Установка:

```sh
# 1. Отдельный пользователь и папка
sudo useradd --system --home /opt/tradingapp --shell /usr/sbin/nologin tradingapp
sudo mkdir -p /opt/tradingapp && sudo chown tradingapp:tradingapp /opt/tradingapp

# 2. Код и зависимости
sudo -u tradingapp git clone https://github.com/qquebak-ai/TradingApp.git /opt/tradingapp
cd /opt/tradingapp
sudo -u tradingapp git checkout claude/trading-app-statistics-5r7nsg
sudo -u tradingapp python3 -m venv .venv
sudo -u tradingapp .venv/bin/pip install -r requirements.txt
sudo -u tradingapp mkdir -p data

# 3. Настройки. Токен генерируем случайный, а не придумываем.
python3 -c "import secrets; print('TRADINGAPP_TOKEN=' + secrets.token_urlsafe(32))"
sudo -u tradingapp cp .env.example .env
sudo -u tradingapp nano .env          # вставь токен, host оставь 127.0.0.1
sudo chmod 600 /opt/tradingapp/.env

# 4. Автозапуск
sudo cp deploy/tradingapp.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now tradingapp
systemctl status tradingapp
```

Дальше — reverse proxy с сертификатом. Готовые примеры лежат в `deploy/`:
`Caddyfile.example` (Caddy сам выпустит сертификат) или `nginx.conf.example`
(плюс `certbot --nginx`). Оба уже содержат увеличенный лимит на размер загружаемого
файла — отчёты MT4/MT5 не помещаются в лимит по умолчанию.

`TRADINGAPP_HOST` в `.env` оставь равным `127.0.0.1`: наружу приложение смотрит
только через proxy, порт 8420 в интернет открывать не нужно.

Открой `https://trading.example.com` с телефона — появится экран входа, введи токен,
браузер его запомнит. Интерфейс адаптирован под телефон: фильтры прячутся за кнопкой
☰, вкладки прокручиваются, таблицы скроллятся по горизонтали.

Обновление до новой версии:

```sh
cd /opt/tradingapp && sudo -u tradingapp git pull && sudo systemctl restart tradingapp
```

### Что дальше

Нажми **«Импорт отчёта»** и загрузи выгрузку из терминала. Чтобы сначала просто
посмотреть, как всё выглядит, загрузи демо-файл `samples/demo_mt4_statement.html`

## Как приложение видит счёт

У MetaTrader нет публичного REST API, поэтому подключений два. Оба дают
одинаковую статистику — отличается только способ доставки истории.

### 1. Импорт отчёта из терминала (работает везде)

- **MT4:** вкладка «Терминал» → «История счёта» → правый клик → *Сохранить как
  детальный отчёт*.
- **MT5:** вкладка «Инструменты» → «История» → правый клик → *Отчёт* → HTML или XLSX.

Перетащи файл в окно импорта. Понимаются HTML, XLSX и CSV, русская и английская
локализации терминала. Повторный импорт того же периода не создаёт дублей:
сделки сверяются по номеру, а изменившиеся суммы (например, доначисленный своп)
обновляются на месте.

### 2. Живая синхронизация с MT5 (только Windows)

Кнопка **«Синхронизировать MT5»** читает историю прямо из запущенного терминала
через официальный пакет `MetaTrader5`. Он существует только под Windows и работает
рядом с установленным терминалом.

```sh
pip install MetaTrader5
```

В настройках терминала должен быть включён «Алгоритмический трейдинг». Если
терминал уже залогинен, логин и пароль указывать не нужно — приложение подключится
к активному счёту. Иначе заполни `MT5_LOGIN`, `MT5_PASSWORD`, `MT5_SERVER` в `.env`.

Синхронизация подтягивает баланс, средства, закрытые сделки и открытые позиции.

### Дашборд на одной машине, терминал на другой

Если MT5 стоит на Windows, а дашборд хочется держать на другом компьютере, запусти
на Windows агента — он читает терминал и отправляет историю по сети:

```sh
python tools/mt5_agent.py --url http://192.168.1.50:8420 --interval 300
```

`--interval 300` — обновлять каждые 5 минут; без него агент отработает один раз.

## Настройки

Скопируй `.env.example` в `.env` и поправь под себя.

| Переменная | Что делает |
|---|---|
| `TRADINGAPP_DB` | путь к файлу базы (по умолчанию `data/trading.db`) |
| `TRADINGAPP_HOST` | `127.0.0.1` — только этот компьютер; `0.0.0.0` — вся локальная сеть |
| `TRADINGAPP_PORT` | порт, по умолчанию `8420` |
| `TRADINGAPP_TOKEN` | пароль к API; открывать как `http://адрес:8420/?token=…` |
| `MT5_LOGIN` / `MT5_PASSWORD` / `MT5_SERVER` | счёт для живого коннектора |
| `MT5_PATH` | путь к `terminal64.exe`, если терминалов несколько |
| `MT5_HISTORY_DAYS` | глубина истории при синхронизации, по умолчанию 10 лет |

**Про доступ с телефона.** Дашборд по умолчанию слушает только `127.0.0.1`, потому
что показывает историю твоего счёта. Если открываешь его на всю сеть
(`TRADINGAPP_HOST=0.0.0.0`), обязательно задай `TRADINGAPP_TOKEN` — иначе счёт
увидит любой в той же сети. В интернет напрямую не выставляй.

## Как считаются метрики

- **Итог сделки** — прибыль плюс комиссия, своп и сборы. Все проценты считаются
  от этой величины, а не от «грязной» прибыли.
- **Стартовый баланс** выводится из текущего баланса счёта минус результат всех
  сделок. Если баланс неизвестен, берётся 10 000 и это помечается в интерфейсе.
- **Просадка** строится по кривой баланса после закрытых сделок. Она не видит
  движения внутри открытой позиции — для этого нужна поминутная история.
- **Риск сделки** считается от расстояния до стоп-лосса: цена одного пункта
  выводится из самой сделки (прибыль ÷ пройденное ценой расстояние), поэтому
  спецификации контрактов не нужны. Сделки без стопа в R-статистику не попадают,
  а её покрытие показано рядом с цифрами.
- **Стоп-лосс в отчёте** — тот, что стоял на момент закрытия. Если стоп переносили
  в безубыток или тралили, исходный риск будет занижен.
- **Часы** — время сервера брокера, как в терминале. Специально не пересчитывается
  в местное: иначе «лучший час» уехал бы относительно того, что ты видел на графике.
- **Отыгрыш после убытка** — вход в течение 30 минут после закрытия убыточной
  сделки объёмом от 1.5 медианы. Это признак поведения, а не приговор: смотри на
  средний результат таких сделок против остальных.

## Разработка

```
backend/app/
  main.py              FastAPI: импорт, синхронизация, API статистики
  models.py            Trade / Account / OpenPosition — общая нормализованная форма
  db.py                SQLite: схема, upsert без дублей, фильтры
  config.py            переменные окружения и .env
  analytics/
    core.py            P&L, кривая баланса, просадка, серии, Sharpe
    grouping.py        общая статистика по группе — база всех разбивок
    breakdowns.py      по инструментам, дням недели, часам, месяцам, длительности
    risk.py            R-мультипликаторы, ровность риска, стопы, перебор, отыгрыш
  ingest/
    readers.py         HTML / CSV / XLSX → таблица строк
    statement.py       разбор отчёта MT4/MT5, RU и EN заголовки
    mt5_live.py        сборка позиций из сделок терминала MT5
frontend/              дашборд без внешних зависимостей: свои SVG-графики
tools/
  mt5_agent.py         агент для Windows: терминал → дашборд по сети
  make_demo_statement.py  генератор демо-отчёта
```

Тесты:

```sh
python3 -m pytest
```

Графики нарисованы вручную на SVG, без библиотек и CDN — приложение полностью
работает офлайн. Прибыль синяя, убыток красный: пара «зелёный/красный» неразличима
при самом частом типе дальтонизма, поэтому рядом с цветом всегда стоит число.
